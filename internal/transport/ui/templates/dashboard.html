Integrity Coverage

Metric Value Meaning
Oldest unverified {{if ne .Data.OldestUnverifiedAge 0}}{{formatDuration .Data.OldestUnverifiedAge}}{{else}}—{{end}} How long the most overdue copy has gone unverified. A copy that has never been checked counts from when it was written, so this reflects the whole backlog rather than only the copies the sweep has already reached. Rises when the scrubber cannot keep pace with the fleet.
Never verified {{if ne .Data.NeverVerifiedCopies 0}}{{formatNumber .Data.NeverVerifiedCopies}}{{else}}—{{end}} Copies that have a content hash but have never been checked against it. On a busy fleet this stays non-zero: newly written copies are unverified until the sweep reaches them, and they are deliberately queued behind older data. Backfill Checksums moves objects out of the No Hash column and into this one, so it climbs by exactly what that pass processed. A steady value is healthy; a climbing one you did not cause is not.
